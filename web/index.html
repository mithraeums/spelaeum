    the chain

    The chain is the model.

    Block 0 is a starting model. Every block after it is a change to the weights and the hash of the block before. Replay it from the bottom and you get the same model, bit for bit. The newest 64, as the coordinator has them:

    a block with a delta mergeda block where nothing passed

    how it works

    One round, five moves.

    1. DealThe last block's hash and your name pick your slice of the data. Nobody chooses their own.
    2. TrainYour machine runs a training job on that slice. As many steps as it can manage.
    3. SendYour result goes in before the round closes. Nobody sees anyone else's until it does.
    4. CheckAll the results together pick the test text. Other trainers check yours on it, each check signed. It has to cut the loss.
    5. MergeEvery result that passes is merged into the block, and the block records who trained it.

    The coordinator keeps the clock and spot-checks the checkers: a key that signs a wrong loss stops checking. Anyone can replay the whole chain and re-run every block's loss, so nobody can fake a block.

    A farm

    works today

    One machine runs a relay, and every phone and desktop on the farm trains through it. The coordinator sees one client.

    spel relay farm \
  --url https://spelaeum.mithraeum.studio --bind 0.0.0.0

    A GPU

    works today

    WebGPU in this tab where the browser has it (Chrome and Edge), OpenCL in the CLI with make GPU=1. Where most of the power is.

    Waiting trainers check each other's work, about a hundredth of a job each, so the coordinator stays a small machine. The data, the model and the blocks download from the mirror on Hugging Face.

    credit

    Credit, counted in work.

    Every job that passes its check counts as the computing it took, and the blocks record whose it was, so anyone can add it up with spel credit.

    The reward: grades are planned to earn perks on the hosted model when it opens, kept to the account that earned them.

    open

    Nothing here needs us.

    The code, the method, the chain and the weights are all GPL-3.0. The chain is the full record of how the model was made, so anyone can rebuild it, run it, host it, or start a chain of their own the same way.

    Run it

    free

    Every weight is in the chain. Replay it and run the model on your own machine.

    Host it, fork it

    free

    The chain is plain files: mirror it on any static host, serve the model, fork the chain, train your own with spel. The GPL asks one thing: what you change stays open too.

    Or use ours

    later

    Once the model is too big for one machine, we host it so you don't have to. Paid use covers the cloud bill and a salary for the person running it. Small models stay free. We don't take your data to pay for it.
